Windows installer guidance

Download only from the official TypeKeys release page and confirm the installer filename matches the release asset. Windows may show a security warning; if the installer does not run, download it again from GitHub and verify the file completed successfully.

macOS build script (experimental)

This is a build helper script, not a macOS installer. I do not have a Mac, so I have not been able to test whether this build works.

  1. Download the script on Windows and transfer build_macos.sh to your Mac.
  2. On the Mac, place it in the root of a complete TypeKeys application source checkout. This website repository does not contain the required app source files.
  3. Open Terminal in that source folder and run bash ./build_macos.sh. The script requires macOS tools, Python 3, and the app's main.py, requirements.txt, and assets/typekeys-logo.png.
Download macOS build script

This does not install TypeKeys on Windows or produce a Mac app on Windows. The script must run on a Mac, and its success is not guaranteed until tested on macOS.

Linux build script (experimental)

This is a build helper script, not a Linux installer. I do not have Linux, so I have not been able to test whether this build works.

  1. Download the script on Windows and transfer build_linux.sh to your Linux computer.
  2. Place it in the root of a complete TypeKeys application source checkout. This website repository does not contain the required app source files.
  3. Open a terminal in that source folder and run bash ./build_linux.sh. The script requires Python 3, tar, main.py, requirements.txt, and assets/typekeys-logo.png.
Download Linux build script

This does not build a Linux app on Windows. Run it on Linux. It creates a portable .tar.gz; it also creates an AppImage only when appimagetool is installed. The script has not been tested on Linux, so success is not guaranteed. Global hotkeys require X11 or XWayland; native Wayland is not supported by pynput.
